# AirPointer 1.7 — Calculator-inspired

## 1.7 介面更新
黑色背景、深灰按鍵、淺灰輔助鍵、橙色主要操作。固定簡報／鍵盤／媒體／語音模式列；媒體及咪高峰採大型圓形按鍵，文字鍵盤保留闊身圓角按鍵。無裝飾漸層／陰影，使用 Android 系統字型，不捆綁 Apple SF Pro。

保留 HID 描述、藍牙配對及現有 Windows 1.6 接收器。英文按鍵直接輸入 PC；手機文字欄只顯示待傳送文字，不讀取 PC 內容。模式間切換保留本次待傳送文字；返回簡報會結束鍵盤工作階段。

[下載最新 APK 與 Windows 接收器](https://github.com/jcwl1008/AirPointer/releases/latest)

## 安裝
下載 AirPointer-v1.7.apk 到 Android 手機，直接安裝更新；套件 com.jimmy.bluepointer、同一簽署，版本代碼 8。Android 9+，手機須支援 Bluetooth HID。保留原有簡報、陀螺儀、翻頁、觸控板與聚光燈操作。

## 新鍵盤
1. 底部固定模式列按「鍵盤」，再在上方切換鍵盤／大觸控板。
2. 上方或鍵盤「🌐」切換 English／繁體速成／繁體手寫。
3. 上方按「觸控板」切換至大觸控板，滑動移動電腦滑鼠、輕點左鍵；下方有左鍵／右鍵按鈕。按「鍵盤」返回輸入。鍵盤使用整個闊度，不再保留窄側邊觸控板。
4. 按右上方「橫向 ⤢」進入橫向全螢幕，再按「直向 ↕」回到直向。橫向按可用高度自動調整按鍵；鍵盤與大觸控板可互相切換；直向主要按鍵靠近下方，方便單手。已移除按鍵大小調整按鈕及舊大小設定。切換時保留待傳送文字、速成碼及手寫筆跡；手寫候選可重新辨識。這是完整 QWERTY 配列，並非桌面鍵盤的實體尺寸。
5. 按「‹ 簡報」或 Android 返回鍵回到直向簡報模式。Ctrl／Alt／Win／Tab／Esc 及方向鍵移到「更多按鍵」。

## English
完整 QWERTY 字母、數字、符號、Shift、Ctrl／Alt／Win、Tab／Esc、方向鍵、Backspace 與 Enter。按鍵直接經 Bluetooth HID 到電腦。請先把電腦輸入法切換到英文；修飾鍵為點選鎖定，再點取消。

## 繁體速成
按倉頡首尾兩碼，候選列顯示固定字序的 1–9 選項，可點字或用數字選字；空白選目前頁首字，左右箭頭切候選頁。文字先留在手機，按「傳送中文」送到電腦。輸入字後可選常用聯想詞。刪除鍵先刪碼，再刪待傳送文字；待傳送文字為空時才刪電腦文字。

碼表源於 Unicode Unihan 18.0.0 的 kCangjie、kFrequency 及繁體異體資料，採固定頻率／字碼排序，約 26,840 個字；固定字序及編號選字借鑑舊式速成操作，但**並非 Windows 95 微軟原版碼表或完全相同候選順序**。聯想詞為約 70 組常用短語，未宣稱完整詞庫。繁體字形取決於手機字型；罕見字可能顯示方框。

## Windows 中文接收器（必須）
英文及滑鼠不需要接收器；中文選字／手寫文字需要附送的小工具。

1. 將整個 desktop 資料夾解壓縮到 Windows 11。
2. 雙擊 Start-Keyboard.cmd 或 AirPointer-Keyboard.exe；系統匣顯示接收器圖示。
3. 點選電腦上要輸入的視窗。
4. 手機按「中文接收器」→「接收器已啟動」。每次重新開啟 App 需確認一次。
5. 選好文字後按「傳送中文」，並查看電腦是否收到。

接收器免安裝、無網絡服務、無文字紀錄，透過 Ctrl+Alt+Shift+F12 啟動的 ASCII 藍牙鍵盤封包接收 Unicode。它只在封包期間擷取十六進位按鍵；驗證長度與校驗碼後注入同一個電腦輸入視窗。超時／封包缺字會取消。一次最多傳送 64 個 UTF-16 單位，分成每組最多 32 單位；請等待傳送完成。**未啟動接收器時不要傳送中文字**，否則可能在電腦打出封包字碼。沒有自動回覆確認，所以「已排入傳送」不代表電腦已收到。

可在系統匣右鍵退出；勿與另一份接收器重複啟動。同樣快捷鍵被其他工具佔用時需先關閉衝突工具。一般權限接收器不能輸入到較高權限程式、Windows 登入或安全桌面。

## 繁體手寫
選擇手寫後，用手指在格內逐筆寫字，按「辨識」，從候選列選字，再按「傳送中文」。首回需按「下載／檢查手寫模型」或「辨識」下載 Google ML Kit 中文模型，下載後可離線辨識。模型支援簡繁字，App 以 Unihan 異體表正規化繁體候選；多義簡繁轉換不一定符合上下文，傳送前請檢查候選字。清除筆跡不會清除已選文字。

ML Kit 19.0.0 的原生辨識庫尚非 16KB 對齊，因此在 16KB 記憶體頁裝置上，App 會改用「使用手機手寫鍵盤」：在 Samsung 鍵盤或 Gboard 選繁體手寫，完成後按「加入文字」。此後文字同樣可以透過接收器傳送。這個套件並未宣稱原生手寫庫的完整 16KB 相容性，亦不是已驗證的 Google Play 上架版本。

## 網絡與資料
英文及速成不需要網絡。手寫模型下載需要網絡，筆跡辨識在裝置進行；App 沒有帳戶、廣告或自建遙測，但 Google ML Kit SDK 可能處理其服務運作資料，見 Google ML Kit 條款及資料披露文件。手機待傳送文字僅存於記憶體，不保存聊天／鍵盤內容。

## 原始碼與建置
需 JDK 17、Gradle 8.9、Android SDK 35／Build Tools 35.0.0。設定 ANDROID_SDK_ROOT、AIRPOINTER_KEYSTORE、AIRPOINTER_KEY_ALIAS、AIRPOINTER_KEYSTORE_PASSWORD 後執行 bash build.sh。沒有附帶簽署私鑰或 Samsung 字型；自行編譯需自己的金鑰，與個人下載版本簽署不同時不能直接更新安裝。

個人製作，並非 Apple、Samsung、Microsoft 或 Logitech 官方產品。實機 Bluetooth、手寫模型下載及完整 Windows 輸入仍需在實際裝置驗證，見 VERIFICATION.md。

## 1.5 長按空白鍵移動文字游標
輕點空白鍵仍輸入空白／選首個速成候選字。長按空白鍵約半秒，手機震動及空白鍵變橙色後，保持手指按住並左右／上下滑動；放開即停止，不會額外輸入空白。

- 速成／手寫模式中有待傳送文字：編輯手機文字游標，可在中間插入／刪除文字。文字欄亦可直接點選游標位置；不會彈出手機鍵盤。左右移動使用完整 Unicode 字元，上下按文字欄實際顯示行移動。
- English 或中文待傳送文字為空：傳送電腦方向鍵，移動目前程式的文字游標。先在電腦點選文字輸入欄，效果由電腦程式決定。這是文字游標移動，不是滑鼠移動。
- 切換鍵盤／觸控板或直／橫向會保留待傳送文字、輸入碼、編輯位置及筆跡。英文已直接送到 PC 的文字不會在手機保存。

## 1.6 媒體控制模式
底部固定模式列按「媒體」。先退出舊 Windows 接收器並啟動本次附送 v1.6 接收器，再在手機按「Windows 接收器」確認已啟動。

提供播放／暫停切換、停止、靜音／取消靜音、音量增加及降低。這些是標準 Windows 系統媒體按鍵，媒體程式需支援相關按鍵；App 沒有讀取電腦播放狀態，不能顯示或保證目前是否播放／靜音。保留原 HID 描述與藍牙配對，不增加新的 consumer-control 報告。

## 1.6 語音輸入模式
底部固定模式列按「語音」，選 English (US) 或粵語（香港）。按咪一次開始，首次需允許咪高峰權限；再按一次停止收音，等待最後結果。手機語音服務可能自動分句，App 會在該次咪啟動期間接續收音，直到再按咪或離開 App；連續未能辨識三次會停止。

結果先加入手機待傳送文字，可點文字欄修改，再按「傳送文字」。英文和粵語語音文字均透過既有 Unicode 接收器送到電腦，不會把錄音發送到電腦。粵語使用 yue-Hant-HK 語言標籤；支援及辨識質素取決於手機已安裝的語音服務及語言資料，App 不能保證所有手機都支援粵語。不支援時會顯示錯誤，可開啟手機語音服務設定。

語音辨識由 Android SpeechRecognizer 的預設服務處理，該服務可能需要網絡，並可能將音訊傳到其伺服器；App 沒有聲稱語音完全離線，亦不保存錄音。按停止、離開 App 或切換模式會停止／取消收音。
